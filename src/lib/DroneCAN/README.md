# DroneCAN DSDL

`dsdl/` holds C serialisers generated by [dronecan_dsdlc](https://github.com/dronecan/dronecan_dsdlc) for the messages used by MAVLink over DroneCAN (`SerialDroneCAN`). They are used with [libcanard](https://github.com/dronecan/libcanard), which is fetched through `dronecan_lib_dep` in `targets/common.ini`.

Generated from:

- DSDL `b4653c7abc3c47cb31b16efa24ea755232774756`, which is newer than ArduPilot's submodule and adds the RCInput `QUALITY_TYPE` constants
- dronecan_dsdlc `de47a8972b7d8c59e50c3acfab5754db29798caa`

## Regenerating

Run this from a scratch directory, with `ELRS` pointing at this repository:

```sh
git clone https://github.com/dronecan/DSDL && git -C DSDL checkout b4653c7
git clone https://github.com/dronecan/dronecan_dsdlc && git -C dronecan_dsdlc checkout de47a89
pip install -r dronecan_dsdlc/requirements.txt
python3 dronecan_dsdlc/dronecan_dsdlc.py -O out DSDL/uavcan DSDL/dronecan

for f in "$ELRS"/src/lib/DroneCAN/dsdl/*; do
    # Local headers use quoted includes so they resolve from this library's folder
    sed -E 's/#include <((canard\.h|uavcan\.|dronecan\.)[^>]*)>/#include "\1"/' \
        "$(find out -name "$(basename "$f")")" > "$f"
done
```

Only the files already in `dsdl/` are kept. To use a new message, copy its `.c`/`.h` and those of any types it depends on.
